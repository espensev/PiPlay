# Change templates

- [Feature design](feature-design-template.md): copy to `docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md` for every non-trivial change. It is the active contract required by the spec-check gate.
- [Implementation plan](plan-template.md): copy to `docs/superpowers/plans/YYYY-MM-DD-<topic>.md` only for multi-step work, then delete it when implementation is complete.

Put durable architecture and product decisions in [`docs/DECISIONS.md`](../../DECISIONS.md). Put unresolved work in [`docs/SPEC_GAPS_AND_OWNERSHIP.md`](../../SPEC_GAPS_AND_OWNERSHIP.md). Do not retain narrative worklogs.
