# UI overhaul discovery

Status: historical discovery evidence for the 2026-06-10/11 UI and theme overhaul. Individual
observations may be stale after the merged implementation passes.

This folder collects exploratory UI evidence and evaluation notes for the PiPlay settings, theme,
popout, and appearance refactor. It is intentionally separate from the formal
`docs/superpowers/specs/` implementation contracts: these files describe what was observed, what the
code said at discovery time, and what needed to be settled before a larger implementation plan.

Contents:

- `ui-state-notes.md` - captured UI states, code-surface mapping, live behavior notes, and change candidates.
- `theme-system-overhaul-evaluation.md` - evaluation of the proposed theme/settings overhaul against current code.
- `address-outline.md` - draft outline converting the discovery findings into prioritized implementation ticket batches.
- `screenshots/` - evidence images referenced by the state notes.

Use this directory for raw discovery material and visual comparison. Current decisions and
implementation contracts live in `docs/superpowers/specs/` and `docs/superpowers/plans/`.
