# PiPlay brand assets

This folder contains reference assets for PiPlay documentation, product identity, and future UI work.
The shipped WPF app still uses its self-contained runtime icon at `src/PiPlay/Assets/piplay.ico`.

- `app-icon/` - cyan play/out-arrow app icon family used as the Windows app/taskbar and Video Popout action identity.
- `monogram-logo/` - `P` monogram logo/favicon family for docs, product identity, and marketing-style surfaces.
